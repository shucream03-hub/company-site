# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」の企業サイトです。
HTML・CSS・JavaScript を1つのファイルにまとめた静的サイトで、ビルドやサーバーは不要です。

## サイトの概要

ビルの階層に見立てて、上から順に次のセクションで構成しています。

| セクション | 内容 |
| --- | --- |
| トップ | キャッチコピー「Build Higher. 上へ、確かに。」と主要な数値（社員数・累計プロジェクト数など） |
| 30F Services | 業務システム開発、クラウド基盤・SRE、モバイルアプリ開発、データ基盤・分析の4事業 |
| 22F Works | 物流・小売・製造分野の導入実績 |
| 15F Process | ヒアリングからリリース・運用までの開発の流れ |
| 8F Company | 代表メッセージと会社概要 |
| 3F Careers | 採用情報 |
| 1F Contact | お問い合わせフォーム |

### 主な特徴

- トップ画面のビル群のイラストは `<canvas>` で描画しています
- ライトモード・ダークモードの両方に対応しています
- お問い合わせフォームは入力チェックのみ行うサンプルで、実際には送信されません

## ファイル構成

```
company-site/
├── skyline-technologies.html  # サイト本体（HTML・CSS・JavaScript）
└── README.md
```

## ブラウザで開く手順

1. このリポジトリをクローンするか、ファイル一式をダウンロードします。
2. `skyline-technologies.html` を開きます。次のどちらの方法でも開けます。
   - エクスプローラー（Mac は Finder）でファイルをダブルクリックする
   - ブラウザのウィンドウにファイルをドラッグ＆ドロップする
3. 既定のブラウザでサイトが表示されます。

コマンドで開く場合は、リポジトリのフォルダで次を実行します。

```sh
# Windows (PowerShell)
start skyline-technologies.html

# macOS
open skyline-technologies.html
```

> フォントは Google Fonts から読み込むため、インターネットに接続した状態で開くと本来のデザインで表示されます。
